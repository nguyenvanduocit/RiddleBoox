Installation and data

What to know before you install.

What do I need to run RiddleBoox?

RiddleBoox needs a BOOX tablet with a pen and Android 10 or later. Before first use, connect the tablet to a computer with ADB and run adb shell settings put global hidden_api_policy 1. The setting survives reboots but must be repeated after a factory reset.

Which AI service can I use?

You bring your own API key. The endpoint and model must accept the app's OpenAI-compatible request format, read images, and stream replies. To use agent tools, they must also support tool calling.

What can an agent access on my BOOX?

Every agent has local memory and a private workspace. Optional capabilities can add access to the BOOX library, reading progress, highlights, and Notes; you choose which agent receives them.

Where does my writing go?

Agent definitions, conversation history, memory, and workspace files are stored locally. For each turn, the page image and relevant conversation, memory, and tool context go directly to the AI provider you configured. There is no RiddleBoox server.

Can I create my own agents?

Yes. Start with a built-in agent or create one with its own name, instructions, greetings, local workspace, memory, and selected BOOX capabilities.
